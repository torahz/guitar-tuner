🚀 Afinador Pro - Quick Start

Problemas Identificados

❌
Erros de dependência:
- UI.showToast não disponível
- Tuner.updateConfig não é função
- Erros de CORS ao abrir localmente
⚠️
Solução recomendada:
Use o servidor local para evitar problemas de CORS

🔧 Solução Rápida

Opção 1: Servidor Local (RECOMENDADO)

Abra o terminal na pasta do projeto e execute:

# No terminal, na pasta do projeto: python server.py

Ou se preferir usar o servidor embutido do Python:

# Alternativa: python -m http.server 8000

Opção 2: Servidor Node.js (se tiver npm)

# Se tiver Node.js instalado: npx http-server -p 8000

Opção 3: Live Server (VS Code)

Se estiver usando VS Code, instale a extensão "Live Server" e clique em "Go Live"

📋 Instruções de Uso

1. Microfone

Permita o acesso ao microfone quando solicitado

2. Detecção Automática

O afinador detectará automaticamente:

  • A frequência da nota tocada
  • Qual corda está sendo afinada (E, A, D, G, B, E)
  • Se está afinada ou desafinada

3. Como Afinar

  1. Toque a corda
  2. Observe a agulha no display
  3. Se a agulha estiver no centro = afinada
  4. Se estiver para a esquerda = afine para baixo (solte a tensão)
  5. Se estiver para a direita = afine para cima (aumente a tensão)

🎯 Dicas

Para melhores resultados:

  • Toque as cordas com força suficiente
  • Evite ruídos de fundo
  • Mantenha o microfone próximo ao instrumento
  • Toque uma corda de cada vez

Problemas comuns:

  • Sem som detectado: Verifique o microfone
  • Notas erradas: Reduza ruídos de fundo
  • Agulha instável: Toque a corda com mais força

🔧 Solução de Problemas

Problema: "UI.showToast is not a function"

Solução: Use o servidor local (Opção 1 acima)

Problema: Microfone não funciona

Solução:

  • Verifique as permissões do navegador
  • Teste o microfone em outro site
  • Reinicie o navegador

Problema: Notas não são detectadas

Solução:

  • Aumente o volume da guitarra
  • Mantenha o microfone mais próximo
  • Reduza ruídos de fundo
  • Toque as cordas com mais força
